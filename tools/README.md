# AI tools and assessments

Start with the [AI Workforce Readiness Assessment](https://paulgibbonsadvisory.com/ai-readiness-assessment/) for an organisational view, or the [AI Adoption Friction Audit](https://paulgibbonsadvisory.com/diagnostics/ai-adoption-friction-audit/) for one specific initiative.

The 17 tools below were listed as **live** on the [canonical tools hub](https://paulgibbonsadvisory.com/diagnostics/) on 2026-09-06. Each opens the working website application. Follow each tool’s own evidence, data-handling, and interpretation notes; a self-report score is not proof of observed behaviour.
